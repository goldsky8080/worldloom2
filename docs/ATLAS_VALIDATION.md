# 월드 아틀라스 검증 · 2026-09-18

환경: Windows, Node 22.9.0, 기존 React/Vite/TypeScript/Pixi. Chromium + SwiftShader, 데스크톱 1440×900 / Pixel 7 412×839. 브라우저 검증은 전용 임시 서버 5192에서 실행합니다.

## 코어와 빌드

- 전체 코어 테스트: 101개 통과(기존 90개 + 아틀라스 11개).
- ESLint: 통과.
- TypeScript / 운영 빌드: 통과.
- Prettier: 통과.
- 통합 설계서 사본과 첨부 원본의 SHA-256이 일치합니다.

아틀라스 테스트는 전역 영지 폴리곤의 틈·겹침, 객체/후보지의 소속, 후보지와 건물의 연결, 왕실 소유/위임 통치 분리, 영지 없는 가문의 유지, 점령 시 발전도 보존, 개방된 영지의 쇠퇴 이력, 원본 데이터 불변성, LOD·레이어 필터, 카메라 범위, 실제 JSON 프레임·등록 키, 잘못된 아틀라스 범위, 로드 실패 재시도, 강화 효과 단계를 확인합니다.

빌드의 아틀라스 화면은 별도 지연 로드 청크입니다: JS 약 59.49 kB(gzip 24.25), CSS 약 16.73 kB(gzip 4.26). 기존 Pixi 청크 500 kB 경고는 유지합니다. 이 수치는 대규모 월드 성능 보증이 아닙니다.

## 실제 브라우저

최종 브라우저 검증: **26개 모두 통과(5.5분)**. 새 아틀라스 10개와 기존 게임 16개를 동일 최종 소스로 실행했습니다.

새 아틀라스 시나리오(각 데스크톱·모바일):

1. 로그인 없이 접속, 실제 WebP/JSON 로드, 전체 지도, 소유·통치 보기, LOD, 선택·광산 정보. 모바일 실제 두 손가락 핀치 입력 포함.
2. 왕실 위임 통치와 30일 임기, 번영→분쟁→쇠퇴에서 소유자·통치자·L4 발전도·공성·파손 상태.
3. 도시 L1/L5·화재 표시와 되돌리기, 아이템 T5/전설/+15 합성, 영지 없는 가문, 언어 전환.
4. 레이어 옵션, 키보드 카메라·줌, 화면 이탈과 재접속에서 캔버스 정리.
5. 아틀라스 503 오류의 명시적 에러 화면과 재시도 복구.

기존 로그인·가입·패널·우편·채팅·다국어, 거리 이동·채광·인벤토리 지급, Gap/Replay·세션 만료·패널 복구도 함께 확인합니다.

초기 검증에서 테스트 선택기가 탭 패널과 입력의 같은 라벨을 중복으로 찾는 문제를 발견하여 입력 역할로 한정했습니다. 장식 기호가 포함된 체크박스도 역할로 선택합니다. 화면 점검을 통해 모바일 레이어 패널을 접고, 지명·마커 크기를 줄였습니다. 최종 브라우저 실행 중에는 런타임 소스를 수정하지 않았습니다.

## 개발·검증 서버 캐시

기존 5190 개발 서버에서 병렬 검증 서버와 공유한 Vite 의존성 캐시가 오래되어 Outdated Optimize Dep 504가 발생했습니다. 기본 개발 캐시는 .cache/vite-dev, Playwright 자동 서버는 .cache/vite-playwright로 분리했습니다. 외부 검증 서버는 WORLDLOOM_VITE_CACHE_DIR=.cache/vite-validation으로 실행합니다. 생성 캐시는 Git과 ESLint에서 제외합니다.

캐시 분리 후 **http://127.0.0.1:5190/atlas**에서 실제 캔버스 1개와 지도 준비 완료를 확인했습니다. 검증용 5192 서버도 별도 캐시로 실행하여 아틀라스·기존 게임 진입을 추가 확인합니다. 기존 개발 서버는 유지하고 작업에서 실행한 임시 서버는 검증 종료 후 닫습니다.

## 재현

```powershell
npm run lint
npm run format:check
npm test
npm run build
npm run test:e2e
```

브라우저가 별도 설치 경로에 있으면 PLAYWRIGHT_CHROMIUM_EXECUTABLE을 지정합니다. 실행 중인 전용 검증 서버를 쓰는 경우 PLAYWRIGHT_EXTERNAL_SERVER=1, PLAYWRIGHT_BASE_URL=http://127.0.0.1:5192로 지정합니다.

이번 구현은 단일 정적 샘플 Region의 지도 표현을 확인합니다. 실제 DB·영유권·전투·세금·경제·유저 수에 따른 확장, 실기기 GPU 부하와 60개 Region 동시 AOI는 시험하지 않았습니다. 기존 /game의 이동·채광과 서버 계약은 유지합니다.

캐시 분리 설정 추가 후에도 아틀라스·기존 게임 진입의 데스크톱 브라우저 2개가 추가 통과했습니다(32.5초). 최종 린트·빌드·포맷 검증이 통과했습니다. 검증용 서버를 종료하고 기존 5190 개발 서버를 유지했습니다.
