# Worldloom2 월드 아틀라스 미리보기 · 2026-09-18

설계 기준: [월드·영지·가문·도시·성·아이템 통합 설계서](spec/WORLD_ATLAS_DESIGN_v0.2.md). 사용자의 “실제로 지도 위에서 어떻게 보일지” 요청에 맞춰 **샘플 대지역 1개를 확인하는 구현**을 추가했습니다. 문서의 실행 대기 지침보다 이번 사용자의 구현 요청을 우선했습니다.

## 바로 보기

개발 서버를 실행한 뒤 **http://127.0.0.1:5190/atlas**에 접속합니다. 로그인 없이 볼 수 있습니다. 로그인 화면의 **월드 아틀라스**, 플레이 지도의 같은 버튼, 월드 메뉴에서도 연결됩니다.

1. 전체 지도에서 영지나 도시·성 마커를 클릭합니다.
2. **소유권 / 통치권**을 바꿔 왕실 소유지와 위임 통치의 차이를 봅니다.
3. **영지 관점 / 현장 관점**으로 선택한 지역을 확대합니다.
4. **미개발 후보지** 레이어에서 비어 있는 성·도시·마을 후보지를 확인합니다.
5. 아래 **개척 / 번영 / 분쟁 / 쇠퇴** 장면을 전환합니다.
6. 객체 패널의 **외형 비교**에서 L1~L5, 공성·화재·폐허 상태를 비교합니다.
7. **아이템 시각화**에서 티어·등급·강화를 각각 바꿉니다.

지도 드래그, 휠·핀치, 방향키와 +/−를 지원합니다. 모바일은 지도 아래 정보 패널을 스크롤하며, 레이어 버튼을 눌러 옵션을 펼칩니다.

## 소유, 통치, 가문

왕실 안전지역은 Crown(왕실)이 소유하며 가문은 30일 위임 통치로 표시합니다. 소유자, 통치자, 시설 운영자는 별도 필드입니다. 가문 레벨·명성·지역 영향력·작위를 분리하고, 장원은 가문 사유 거점으로 표시합니다.

가문은 이동 객체가 아닙니다. 지도에는 성·도시·장원·깃발·문장이 표시됩니다. 길벗 용병 가문은 영지가 없는 성장 사례로 남습니다. 파티를 별도 지도 객체로 추가하지 않았습니다.

문장은 6종 방패, 8종 문양, 20종 상징, 5종 깃발, 6종 작위 장식 변형과 두 색상을 SVG로 조합해 React와 Pixi에서 공유합니다. 가문별 개별 이미지 파일을 만들지 않습니다. 이 미리보기에서는 문장 부품을 코드 기반 벡터로 구성하며 문장 전용 래스터 아틀라스는 후속 아트 작업입니다.

## 성장과 역사 장면

- **개척의 시작**: 왕실 안전지역과 초기 가문 소유지, 미개척 영지와 후보지.
- **성장과 번영**: 비활성 영지 개방, 거점 성장, A-15 새벽 마을 생성.
- **변경의 분쟁**: 통치권 변경과 공성·손상 오버레이. 도시의 소유권과 L4 발전도는 유지합니다.
- **쇠퇴와 흔적**: 일부 영지는 쇠퇴·폐허로 남으며 열린 영지, 도시 레벨과 가문 기록을 삭제하지 않습니다.

각 장면은 기본 샘플을 복제해서 표시합니다. 장면 버튼으로 과거 모습도 다시 볼 수 있습니다. 실제 서버 명령, 영유권 획득, 세금, 전투나 자원 지급을 실행하는 기능이 아닙니다. 외형 슬라이더 역시 선택 객체의 표시만 바꾸며 종류 승격을 실행하지 않습니다.

## 아틀라스와 렌더링

실제로 생성한 미리보기 자산:

| 아틀라스          | 프레임 | 이미지 크기 |
| ----------------- | ------ | ----------- |
| world-settlements | 32     | 2048 × 1024 |
| world-objects     | 16     | 1024 × 256  |
| item-bases        | 10     | 1024 × 256  |
| common-overlays   | 19     | 1024 × 384  |

원본은 코드로 만든 SVG 시트이며 같은 좌표의 WebP와 JSON을 생성합니다. JSON이 좌표를 관리하고 렌더러·React 컴포넌트는 프레임 키를 사용합니다. 도시·성·마을·소도시는 L1~L5, 장원·전초기지·항구·광산은 L1~L3입니다. 도시·성 레벨은 건물 개수, 본성·탑·성벽·시장 등의 구성으로 달라집니다.

AssetManager는 아틀라스·프레임 등록, JSON 규격·프레임 범위·필수 프레임·이미지 실제 크기 검증, 로드 캐시와 실패 재시도를 지원합니다. 기존 개별 이미지 Resolve/Fallback 계약은 유지합니다. 프레임 텍스처는 시트 소스를 공유하고 장면 종료 시 공유 소스를 파괴하지 않습니다. 문장 텍스처와 ResizeObserver·입력 이벤트는 정리합니다.

WorldObjectRegistry가 객체 종류의 시각 메타데이터와 깊이를 관리합니다. Entity에는 소유·통치·발전 데이터가, Visual에는 atlasId/frameKey/anchor/zIndex/LOD가 있습니다. 렌더링은 변경이나 입력 때 수행하고 매 프레임 반복 렌더링하지 않습니다.

LOD:

- Far(멀리), 줌 < 0.23: 수도·도시·성·주요 장원·세계 이벤트.
- Medium(중간), 줌 < 0.6: 소도시·마을·광산·던전·운송·시설.
- Near(가까이): 플레이어·NPC·몬스터·개별 자원.
- 화면 밖 객체는 숨깁니다. 레이어 옵션은 각 LOD 필터와 함께 적용합니다.

아이템은 본체 티어 T1~T5, 등급 프레임 5종, 강화 효과 5단계(+0은 없음), 숫자 +0~+15를 각각 합성합니다. 미리보기 대상은 곡괭이·검 두 종류이며 실제 장비 강화나 강화 확률은 구현하지 않습니다.

## 기존 v0.2 연결과 후속 범위

기존 React/Vite/TypeScript/Pixi, Module Registry, AssetManager를 확장했습니다. /game의 WorldEntity, GameGateway, GameRuntime, GameCache, Command/Event, Chunk/AOI, 거리 이동·채광 계약과 월드 2400×1600은 유지합니다.

샘플은 /atlas의 별도 읽기용 모듈입니다. 대규모 월드의 영지 영역 모델과 기존 소규모 플레이 월드를 바로 한 계약으로 합치면 AOI·이동 시간·서버 저장 구조를 확정해야 하므로, 이번에는 지도 표현 검증을 먼저 제공합니다.

200,000×120,000과 약 60개 Region은 **잠정 논리 월드 미니맵 표기**이며 실제 60개 지역을 제작하거나 구독하지 않습니다. 실제 가문 DB, 월드 확장 압력, 탐사·영유권 명령, 경제 시뮬레이션, 공성전·세금·선거·작위 공식은 후속 설계 범위입니다. 현재 시각 자산은 코드 기반 미리보기이며 최종 아트가 아닙니다. 기존 사용자 WebP 자산은 보존했습니다.

주요 파일: src/modules/atlas/, src/services/assets/atlas.ts, AssetManager.ts, 모듈 등록·라우터 연결, public/assets/{world,items,common}/atlas/, scripts/build-preview-atlases.mjs.

아틀라스 재생성:

```powershell
node scripts/build-preview-atlases.mjs
```

설치된 Chromium 경로가 다르면 PLAYWRIGHT_CHROMIUM_EXECUTABLE을 지정합니다. 새 라이브러리는 추가하지 않았습니다.

검증 결과와 화면은 [ATLAS_VALIDATION.md](ATLAS_VALIDATION.md)에 기록합니다.
