# Fief Management v0.3

기준: [영지 통합 설계서 v1.0](spec/FIEF_SYSTEM_INTEGRATED_v1.0.md), [v0.3 실행 프롬프트](spec/FIEF_MANAGEMENT_EXECUTION_v0.3.md). 기준 커밋 f69aecc의 지도 중심 플레이를 확장했습니다.

## 접속과 운영 흐름

**http://127.0.0.1:5190/fief**에서 로그인 없이 테스트 영주의 영지 1개를 관리합니다. 성·도시·장원 L1, 영구 던전 고대 지하궁전으로 시작합니다.

1. HUD의 내부 에테르와 외부 **몬스터 포화도**를 확인합니다.
2. 성에서 정상 병사를 **상시 토벌대**로 배치합니다. 반복 출격 없이 포화도를 억제하지만 병력 손실을 점검해야 합니다.
3. 병력이 부족해지기 전에 인원을 정해 **모병**합니다. 비용은 시작에 차감하고 병사는 시간이 지난 뒤 편입됩니다.
4. 내부 에테르는 던전의 직접 공략 또는 가상 모험가 의뢰로 관리합니다.
5. 폭주하면 포화도가 크게 뛰고 몬스터 웨이브가 도시로 이동합니다. 가용 병력으로 **긴급 토벌대**를 보내 외부 위험을 낮춥니다.
6. 방치하면 치안→번영도→민심 순으로 빠르게 손상됩니다. 원인을 해결한 뒤 안정 기간을 유지해야 회복합니다.
7. 장원에서 세금과 활성 정책을 조절하고 세입·병력·정책 유지비의 정기 결산을 확인합니다.

브라우저 메모리 시뮬레이션입니다. 새로고침·화면 재진입은 초기 상태로 돌아갑니다. 실제 백엔드·DB·WebSocket·오프라인 진행은 추가하지 않았습니다.

## 지도·시설 패널

데스크톱은 지도와 우측 선택 시설 패널, 412px 모바일은 HUD→지도→하단 시설 패널을 유지합니다. 페이지 스크롤과 상황 패널 스크롤로 긴 군사·행정 행동에 접근합니다.

HUD는 금고, 민심·치안·번영도와 4단계 상태, 던전 등급·주기, 에테르·포화도를 항상 표시합니다. 성에는 정상/부상/누적 전사/방어 가용/상시 배치/긴급 배치, 생존 병력과 정원을 표시합니다. 상시 토벌대는 경비병 왕복 마커, 긴급 토벌대는 더 큰 병력 마커, 던전 폭주는 기존 도시행 몬스터를 사용합니다.

장원은 세금·정책 슬롯·해금·쿨다운과 결산, 도시는 상태·회복 대기·경제 설명, 던전은 등급·주기·공략·의뢰를 제공합니다. 긴 이론 규칙은 정상 화면에 펼치지 않습니다.

기존 AtlasSprite/AssetManager의 실제 프레임만 사용합니다. 장원은 실제 등록된 L1 프레임을 재사용하고 DEV 레벨은 표기와 정책 슬롯·해금에 반영합니다. 외부 이미지·애니메이션 라이브러리·새 패키지를 추가하지 않았습니다. 한국어·영어·일본어·중국어·베트남어, 실제 button/input, 44px 행동 버튼, 포커스·progressbar·status·alert를 제공합니다.

## 병력과 모병

- 생존 병력 = 정상 + 부상. 전사자는 누적 통계이며 정원을 차지하지 않습니다.
- 성 방어 가용 = 정상 − 상시 배치 − 긴급 배치.
- 배치 인원은 정상 병력의 일부입니다. 생존 병력에 다시 더하지 않습니다.
- 상시 배치는 0명으로 해제할 수 있습니다. 긴급 배치와 겹치는 정상 병사를 사용할 수 없습니다.
- 모병 작업은 1개입니다. 시작 비용·시간은 시작 시 확정하여 정책 변경 후에도 유지합니다.
- 진행 중 모집 인원은 정원을 예약합니다. 부상도 정원을 사용합니다.
- DEV 성 하향 변경으로 현재 생존 + 예약 인원이 새 정원을 초과하면 변경을 거부합니다. 병사를 임의로 삭제하지 않습니다.
- 부상병은 각 부상 시점으로부터 30초 후 자동 회복합니다. 회복 후 상시 배치에 자동 재투입하지 않습니다.
- 상시 토벌의 손실 누적량은 배치를 해제·재개해도 보존합니다. 긴급 생존자는 완료 시 가용 병력으로 돌아옵니다.

## 포화도·토벌·폭주

몬스터 포화도는 0~100의 외부 몬스터 밀도입니다. 에테르 100만 던전 폭주를 일으킵니다. 포화도 100은 폭주를 직접 발생시키지 않습니다.

자연 증가 = 초당 기본값 + 등급 인덱스 × 추가값입니다. 상시 억제량은 배치 인원 × 병사당 효과 × min(1, 포화도/효율 경계값)입니다. 낮은 포화도에서는 효율이 감소하여 자연 증가와 균형을 이룹니다. 이 구간은 지수 해로 정확히 진행하며 Euler 근사에 의존하지 않습니다.

상시 피해는 인원·포화도 단계에 따른 노출량을 누적합니다. 임계량마다 1명의 손실이 발생하고 매 4번째 손실은 전사, 나머지는 부상입니다. 실제 정상·배치 병력이 함께 감소합니다. Math.random은 사용하지 않습니다.

폭주 ID마다 포화도 +35와 웨이브를 한 번 생성합니다. 웨이브 아이콘 수는 증가 후 포화도 기준 3/4/5개입니다. 에테르를 줄여도 이미 출발한 웨이브는 남고, 도착 피해는 각 ID마다 한 번입니다. 회복 후 새 폭주가 발생하면 기존 웨이브와 함께 진행합니다.

## 상태 손상·회복

| 수치   | 구간 |
| ------ | ---- |
| 80~100 | 안정 |
| 60~79  | 주의 |
| 30~59  | 불안 |
| 0~29   | 위기 |

높은 포화도는 치안·번영도·민심에 서로 다른 지속 손상을 줍니다. 웨이브의 1회 피해와 별도로 적용합니다. 수치 하락이 다른 수치를 직접 다시 깎는 무한 악순환은 없습니다.

치안 회복 조건은 포화도 안전권, 활성 폭주 없음, 접근 웨이브 없음, 성 방어 가용 병력 존재입니다. 5초 안정 후 회복합니다. 번영도는 같은 안전 조건에 치안 80 이상을 15초 유지해야 합니다. 민심은 같은 조건에 번영도 위기 아님을 포함하여 30초 유지해야 합니다. 각 조건이 끊기면 해당 타이머를 초기화하고, 폭주·웨이브 도착은 전체 안정 타이머를 초기화합니다.

80 이상에서는 자연 회복을 20% 속도로 낮춥니다. 안전한 영지는 관리만으로 100까지 회복할 수 있습니다. 정책은 조건과 안정 기간을 생략하지 않고 회복 속도를 보조합니다.

## 장원·금고

금고는 개인 지갑과 구분한 운영 자금입니다. 인출·개인 지갑은 구현하지 않습니다.

세금은 LOW/NORMAL/HIGH이며 변경 후 20초 쿨다운입니다. 낮은 세율은 세입을 줄이고 민심·번영도 회복을 돕습니다. 높은 세율은 세입을 늘리지만 두 상태에 장기 부담을 줍니다. 즉시 ±10 같은 효과는 없습니다.

장원 L1~5 정책 슬롯은 **1/1/2/2/3**입니다. 각 정책 활성·해제에는 20초 쿨다운을 사용합니다. 새 정책은 한 결산분 유지비를 보유해야 활성화할 수 있습니다.

| 정책      | 해금 장원 | 30초 유지비 | 효과                          |
| --------- | --------- | ----------- | ----------------------------- |
| 주민 지원 | L1        | 60 G        | 민심 회복 ×1.6                |
| 치안 지원 | L1        | 60 G        | 치안 회복 ×1.6                |
| 상업 지원 | L2        | 60 G        | 번영도 회복 ×1.6              |
| 모병 지원 | L2        | 50 G        | 새 작업 비용 ×0.8, 시간 ×0.75 |
| 재건 지원 | L4        | 100 G       | 세 상태의 조건부 회복 ×1.5    |

30초마다 세입을 먼저 입금하고 생존 병력 유지비를 지급한 뒤 정책 유지비를 처리합니다. 정책 총비용을 감당하지 못하면 활성 정책을 모두 중지하고 정책 비용은 차감하지 않습니다. 병력 유지비는 보유 금액까지만 지급하고 부족액을 경고합니다. 부채·즉시 병사 삭제·탈영·게임 오버는 없습니다. 경고는 다음 결산 결과로 갱신됩니다.

예상 세입 = floor(300 × 도시 레벨 × (0.25 + 0.75 × 번영도/100) × 세율 배수). 실제 NPC 경제·교역·생산이 아닌 결정론적 세입입니다.

## 시간·개발 도구·후속

advanceFief 한 곳에서 모든 시간을 진행하며 포화도·상태 경계, 손실·모병·긴급·부상 회복·결산·공략·웨이브·주기 경계를 정확히 나눕니다. 동시 경계는 폭주→공략·의뢰→도시 도착→부상 회복·모병·긴급·상시 피해·결산→주기 순으로 처리합니다.

React interval은 250ms 하나입니다. pause는 전체 시간을 멈추고 DEV +30초는 전체 모델을 진행합니다. hidden 탭의 시간을 합산하지 않으며 활성 지연은 최대 5초를 반영합니다. StrictMode·화면 이탈에서 interval·visibility·Escape 리스너를 정리합니다.

DEV 기본 닫힘을 유지합니다. 도시·성·장원 레벨, 시간 모드·정지·진행·다음 주기, 에테르·포화도 증가/감소, 즉시 공략·폭주·금고 지원/비우기·영지 상태 30·초기화는 개발 도구 안에만 있습니다. 정상 화면에는 무료 돈·실제 시설 업그레이드를 추가하지 않았습니다.

실제 백엔드·DB·멀티플레이어 의뢰·전투·인구·반란·작위·귀족 평의회·전쟁·공용 월드 던전·전문 병종·의무실·개인 인출·교역·생산·자원 건설은 후속입니다. 도시 ≤ 성+1 후보 규칙은 강제하지 않습니다.
