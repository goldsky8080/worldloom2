# 인스턴스 영지 프로토타입 v0.1

기준: [영지 시스템 기능 설계서 v0.2](spec/FIEF_SYSTEM_DESIGN_v0.2.md), 2026-09-18.

## 접속과 첫 확인

개발 서버의 **http://127.0.0.1:5190/fief**에서 로그인 없이 테스트 영지 1개를 엽니다. 로그인 화면의 영지 관리, 아틀라스 상단의 영지 관리, 기존 게임의 월드 메뉴에서도 진입합니다. 작위를 가진 테스트 영주로 가정하며 실제 작위 권한을 발급하지 않습니다.

새벽물결 영지는 개인 관리 공간입니다. 기존 공용 아틀라스의 16개 영지 폴리곤에 새 플레이어 영지를 추가하지 않습니다. /atlas는 월드 설계 미리보기, /game은 기존 거리 이동·채광 루프, /fief는 독립 관리 프로토타입입니다.

처음 성 L1, 도시 L1, 장원 L1, 고대 지하궁전 1개가 있습니다. 지도 또는 시설 카드에서 역할을 선택하고, 도시·성 레벨 입력은 테스트용으로 조작합니다. 업그레이드 비용·조건·최대 운영 레벨을 확정하지 않습니다. 장원은 L1을 유지합니다.

## 던전 등급과 주기

| 도시 | 다음 주기 등급 범위 |
| ---- | ------------------- |
| L1   | F / E / D           |
| L2   | D / C               |
| L3   | D / C / B           |
| L4   | C / B / A           |
| L5   | B / A / S           |

고정 시퀀스의 선택 인덱스는 (주기 번호 − 1) % 허용 등급 수입니다. 운영 난수·가중치·관리 성과 반영은 미정입니다. 도시 변경은 **다음 주기**부터 반영하므로 L5 던전 S가 진행 중일 때 도시 L1로 바꿔도 이번 주기의 S는 유지됩니다. 다음 주기는 F~D에서 결정됩니다. 성 레벨은 등급 선정에 참여하지 않습니다.

초기 등급은 F입니다. 가속 모드는 120초 후 주기를 자동 갱신합니다. 테스트용 다음 주기 실행은 남은 시간 대기 없이 새 주기를 시작하며 에테르를 리셋하지 않습니다. 시간 +30초는 선택한 모드의 시간 30초를 진행하고 중간 주기 경계를 정확히 처리합니다.

운영 설계 상수는 21일(1,814,400초)입니다. 설계 시간 모드는 브라우저 내부 시간이 이 상수를 사용하도록 비교하는 기능이며, 실제 서버 스케줄러가 아닙니다. 모드 변경은 현재 주기 진행 비율을 보존합니다.

가속 모드는 남은 30초부터 다음 등급을 예고합니다. 설계 시간 비교 모드는 마지막 1일부터 예고합니다. 둘 다 테스트용 공개 시점입니다. 예고 후 도시를 변경하면 새 허용 범위로 예고를 다시 계산하며 실제 다음 주기 등급과 일치합니다.

영구 던전의 ID·위치·이름은 유지합니다. 주기마다 등급에 따라 몬스터·보스·자원 샘플이 바뀝니다. 그 목록과 등급별 조합은 표시용 샘플이며 보상·드롭 테이블을 확정하지 않습니다.

## 에테르와 폭주

테스트 규칙:

- 초기 에테르 12 / 100.
- 가속 모드에서 초당 0.6 + 등급 인덱스 × 0.12 증가. F 인덱스는 0, S는 6입니다.
- 설계 시간 비교 모드는 같은 주기당 변화량을 21일로 늘려 적용합니다.
- 안정 <35, 불안정 35~64.99, 위험 65~84.99, 폭주 임박 85~99.99, 폭주 100.
- 모의 던전 공략 1회당 −35, 최소 0.
- 최대치 도달 시 폭주 기록·몬스터 웨이브 경고·지도 위험 영역 표시.
- 최대치에 머무르는 동안 같은 폭주를 반복 집계하지 않습니다.
- 공략으로 100 미만으로 내리면 현재 위험 상태가 낮아집니다. 누적 폭주 기록은 보존합니다.
- 주기 갱신으로 에테르나 폭주를 자동 초기화하지 않습니다.

실제 전투·시설 파괴·재화·전리품은 연결하지 않습니다. 반복 공략 버튼은 전투 완료를 대신하는 개발 도구이며, 영주 혼자 장기 관리 가능한 운영 규칙을 뜻하지 않습니다.

성 관리 여력 표시는 등급 인덱스 − 1(최소 1)을 필요 레벨로 삼은 임시 비교입니다. 같은 이상 성 레벨이면 여력 있음, 1 낮으면 부담 증가, 더 낮으면 부족으로 표시합니다. 군사 수치·병사·유지비·실제 순찰을 시뮬레이션하지 않습니다. 성 레벨을 올려도 내부 에테르 증가량과 던전 등급은 바뀌지 않습니다.

## 시간과 수명

시간 일시정지는 에테르와 주기 자동 진행을 함께 멈춥니다. 수동 시간 조작은 정지 중에도 가능합니다. 숨겨진 탭에서는 진행하지 않으며 다시 표시되면 기준 시각을 갱신해 오프라인 시간을 더하지 않습니다. 화면 활성 중 프레임 지연은 tick당 최대 5초만 반영합니다.

페이지를 떠나면 interval과 visibilitychange 리스너를 해제합니다. 새로고침·재진입·영지 초기화는 초기 상태로 돌아갑니다. 서버 DB나 브라우저 저장소에 영지를 보관하지 않습니다. 초기화하면 자동 진행도 재개합니다. 최근 관리 기록은 최대 12개입니다.

아틀라스의 기존 WebP/JSON 도시·성 레벨 프레임, 장원·던전 프레임을 AssetManager와 AtlasSprite로 재사용합니다. 새 Pixi 루프·외부 라이브러리는 추가하지 않습니다. 기존 GameRuntime·Command/Event·이동·채광 계약을 수정하지 않습니다.

## 후속 범위

실제 왕·작위 경쟁·다중 영지·경제·세금·민심·반란·작위 박탈·시설 파괴·군대 전투·플레이어 간 의뢰·서버 영속화·21일 서버 스케줄러는 후속입니다. 공용 월드 던전 생성/소멸과 SS 이상 다중 파티 레이드도 이번 범위 밖입니다.

첨부 문서의 '별도 실행 프롬프트 후 개발' 안내는 문서 상태 설명으로 구분했습니다. 이번 사용자 요청에 따라 문서 19~22장의 첫 프로토타입 목표를 구현하고, 미확정 운영 수치를 확정하지 않습니다.
