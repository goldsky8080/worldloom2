# 영지 프로토타입 검증 · 2026-09-18

환경: Windows, Node 22.9.0, 기존 React/Vite/TypeScript/Pixi 프로젝트. 실제 Chromium + SwiftShader, 데스크톱 1440×900 / Pixel 7 412×839. 테스트 서버는 전용 5187, 기존 개발 서버는 5190입니다.

## 코어와 빌드

- 전체 코어 테스트 **115개 통과**: 기존 101개 + 영지 14개.
- ESLint 통과.
- TypeScript·운영 빌드 통과.
- Prettier 통과.
- 첨부 원본과 docs/spec/FIEF_SYSTEM_DESIGN_v0.2.md의 SHA-256 일치: 8EF78072BEE1E917688DA244E553E376975DE7D6833B93D778D6876D937701CC.

영지 테스트는 초기 시설·영구 던전, 5개 도시 레벨의 정확한 허용 등급, 도시 변경의 다음 주기 적용·하향 변경, 성 레벨과 등급·에테르의 독립, 주기 경계 전후의 시간 증가율, 던전 ID와 에테르 보존, 위험 경계, 폭주 중복 집계 방지·재폭주, 공략 0 하한·상태 불변성, 예고와 실제 새 등급 일치, 시간 모드 진행 비율 보존, 기록 크기·고유 ID, 잘못된 레벨·시간 입력을 확인합니다. 모든 시설 레벨의 실제 아틀라스 키도 등록 목록에 존재하는지 검사합니다.

영지 화면은 별도 지연 로드 청크입니다. 새 패키지는 없습니다. 기존 Pixi의 500 kB 청크 경고는 빌드 실패가 아닙니다.

## 실제 브라우저

신규 영지 **12개 통과**(6개 시나리오 × 데스크톱·모바일, 약 1.1분):

1. 로그인 없이 초기 시설·영구 던전, 실제 WebP 로드, 시설 선택, 가로 넘침 없음, 실제 휠로 내부 페이지 스크롤.
2. 도시 L5 변경 시 현재 F 유지, 다음 주기 A→S, 성 L5 변경 시 S 유지, 도시 L1 하향 변경 후 다음 주기 F, 예고 일치.
3. 시간 증가→에테르 100→폭주 경고·누적 1회, 최대치 중복 집계 없음, 공략 후 65·위험으로 회복, 반복 공략 0·버튼 비활성, 초기화.
4. Playwright 브라우저 시계로 자동 시간 증가·주기 갱신, 일시정지·재개. visibility API를 숨김으로 전환하여 숨김 동안 증가하지 않음과 다시 표시될 때 시간 누적 없음 확인.
5. 2분 주기 1/4 진행 후 설계 시간으로 전환하면 21일의 3/4인 15일 18시간 남음. 한국어·영어·일본어·중국어·베트남어 전환.
6. /fief→/atlas→/fief 왕복에서 Pixi 캔버스 생성·제거와 영지 초기화, 새로고침 초기 상태.

기존 게임·아틀라스 **26개 회귀 테스트 통과**(데스크톱·모바일). 거리 이동·채광·인벤토리 지급, 로그인·가입·패널·우편·채팅·다국어, Gap/Replay·세션 만료·패널 복구, 아틀라스 LOD·실제 모바일 핀치·소유/통치·장면·아이템·오류 재시도를 확인했습니다.

헤더 스타일의 마지막 조정 후 영지 초기 화면 **2개 추가 통과**. 고유 브라우저 시나리오는 총 **38개**입니다.

## 발견·수정·화면 검수

첫 브라우저 실행에서 정착지 프레임의 접두사가 기존 등록 키와 다른 것을 발견해 settlement.city/castle/manor 키로 수정하고 모든 레벨 자산 연결 테스트를 추가했습니다. 실제 화면에서는 전역 게임 스타일이 페이지 스크롤을 막는 문제를 찾아 /fief에 독립 스크롤을 적용했습니다. 헤더 링크가 좁게 줄바꿈하는 것도 수정했습니다.

실제 데스크톱·모바일 스크린샷으로 지도·시설·상태 패널 배치를 확인합니다. overview는 페이지 처음, cycle은 관리 조작 위치, break는 경고가 보이는 페이지 처음을 기록합니다. 내부 스크롤 페이지이므로 각각의 뷰포트 캡처입니다.

## 재현

```powershell
npm test
npm run lint
npm run build
npm run format:check
npm run test:e2e
```

별도 설치 Chromium을 사용할 경우 PLAYWRIGHT_CHROMIUM_EXECUTABLE을 지정합니다. Playwright 서버는 기존 개발 서버와 다른 .cache/vite-playwright 캐시를 사용합니다.

이 검증은 클라이언트 프로토타입의 동작을 확인합니다. 서버 DB·21일 운영 스케줄러·실제 작위 권한·경제·전투·타인과의 의뢰·월드 레이드·실기기 GPU 성능은 시험 범위가 아닙니다.
